# API analysis

Inventory externally exposed and internal endpoints from route registration, controllers/handlers, schemas, middleware, and generated specifications. For each selected flow record method/protocol, path/operation, authentication/authorization, validation, handler, request/response model, error mapping, side effects, downstream calls, and tests.

Differentiate public APIs, internal/admin APIs, callbacks/webhooks, and health endpoints. Treat an interface or OpenAPI entry without implementation as contract evidence only. Examine pagination, rate limits, idempotency keys, input size, authorization scope, and sensitive-field handling where code exists.
